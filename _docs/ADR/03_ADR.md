# ADR-003: Внедрение Event Bus, Логгера и Анти-спам кэша

**Дата создания:** 2026-03-08
**Статус:** `Completed`
**Связанные Epic/Task:** Этап 3 (ROADMAP.md)

---

## 1. Контекст и Бизнес-задача (Context)
* В рамках Этапа 3 необходимо внедрить событийно-ориентированную архитектуру для слабой связанности фич (Feature-First) и научиться сохранять историю сигналов для ретроспективного анализа.
* Во время тестов Этапа 2 выявлена проблема: при открытом окне арбитража оригинальный сканер генерирует десятки дублирующихся сигналов в секунду. 
* Бизнес-задача: Защитить систему (в частности шину событий и файловую систему) от спама, реализовав In-memory кэш с TTL (Time-To-Live) в 60 секунд. Данная задача логически перенесена из Этапа 4 в Этап 3.

## 2. Предлагаемое решение (Proposed Solution)
* **Event Bus:** Использование нативного модуля `EventEmitter` из Node.js. Создание строгой типизированной обертки `EventBus` в слое `core/`, чтобы гарантировать тип передаваемых данных (`ISignalPayload`) в событии `SignalDetectedEvent`.
* **Config:** Добавление константы `ANTI_SPAM_TTL_MS` (по умолчанию 60000 мс) в `config.ts` и документирование всех параметров через комментарии.
* **Anti-Spam Filter (Scanner):** Внедрение `Map<string, number>` (где ключ — тикер, значение — timestamp последнего пропущенного сигнала) непосредственно в `src/features/scanner.ts`. Если сигнал не проходит проверку TTL, он молча отбрасывается. Если проходит — отправляется в Event Bus.
* **Logger:** Создание модуля `src/features/logger.ts`, который подписывается на Event Bus и производит асинхронную запись (append) в формате JSON Lines в файл `logs/signals_log.jsonl`.
* **DI Container (Main):** Рефакторинг `main.ts` для инициализации `EventBus`, передачи его в логгер и сканер, связывая компоненты воедино. Вывод в консоль производится только для уникальных сигналов, прошедших спам-фильтр.

## 3. Изменения в Данных и Состоянии (Data & State)
* **БД:** Отсутствует.
* **State:** Появление локального In-memory состояния внутри модуля `scanner.ts` — коллекция `Map` для отслеживания времени поступления сигналов по тикерам.
* **FS:** Добавление механизма работы с файловой системой. Автоматическое создание директории `logs/` и дозапись (append-only) в файл `signals_log.jsonl`.

## 4. Интеграции и AI (Integrations)
* Интеграции не меняются. Сохраняется механизм "AI-First Observable" через `DEBUG_RAW_SIGNALS`.

## 5. Затронутые файлы (Affected Files)
* `config.ts` — Изменить: добавить JSDoc комментарии ко всем полям и добавить параметр `ANTI_SPAM_TTL_MS`.
* `src/core/event_bus.ts` — Создать: реализовать класс `AppEventBus` на базе `EventEmitter`.
* `src/features/scanner.ts` — Изменить: внедрить In-memory кэш, логику проверки TTL и публикацию события в Event Bus.
* `src/features/logger.ts` — Создать: реализовать функцию подписки на Event Bus и записи в `logs/signals_log.jsonl`.
* `src/main.ts` — Изменить: убрать прямой `console.log` сигналов, инициализировать `AppEventBus` и `logger`, передать экземпляр шины в обработчик веб-сокетов.

## 6. Пошаговый план реализации (Execution Steps)
1. Обновить `config.ts`: добавить `ANTI_SPAM_TTL_MS: 60000` и подробные комментарии к каждому параметру.
2. Создать `src/core/event_bus.ts`: импортировать `EventEmitter` и `ISignalPayload`, создать класс `AppEventBus` с методами `emitSignal` и `onSignal`.
3. Создать `src/features/logger.ts`: написать функцию `initLogger(eventBus: AppEventBus)`, которая проверяет/создает папку `logs/`, слушает `onSignal` и делает `fs.promises.appendFile(..., JSON.stringify(payload) + '\n')`.
4. Отрефакторить `src/features/scanner.ts`: 
   * Добавить на уровне модуля переменную `spamCache = new Map<string, number>()`.
   * Изменить сигнатуру функции (передавать `EventBus` или возвращать массив отфильтрованных сигналов). *Архитектурно чище возвращать отфильтрованный массив из функции парсинга, а публикацию делать в `main.ts`*.
   * Реализовать логику `Date.now() - (spamCache.get(symbol) || 0) > config.ANTI_SPAM_TTL_MS`.
5. Отрефакторить `src/main.ts`: инстанцировать `AppEventBus`, вызвать `initLogger`, получать массив чистых сигналов из `scanner.ts`, делать `console.log` и вызывать `eventBus.emitSignal(signal)`.
